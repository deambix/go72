# GO 72

A mobile-first lifestyle storefront and PWA prototype, built with Vite, vanilla JavaScript, HTML and CSS. Original placeholder products and SVG illustrations; no real commerce integrations.

Implementation and cloud quality checks are in progress. Vercel setup will be handled by the repository owner.

## Development

Use Node.js 22.12 or newer.

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Responsibility

The developer builds the website. The business owner is responsible for products, orders, payments, fulfilment, refunds, policies, taxes, compliance and customer support.
